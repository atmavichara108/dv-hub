
# Roadmap

## Phase 0: Local foundation (сейчас)
Локальная разработка Node.js + SQLite, MVP-сценарии работы с темами и комнатами. Публичный хостинг отложен и не является условием продолжения разработки.

Ключевые задачи: DV-001..DV-027 (см. DV/Operations/Kanban).

**Definition of Done фазы**:
- проект воспроизводимо запускается на localhost без внешних сервисов;
- защищённые сценарии доступны через строго локальную dev-auth;
- миграции, тесты и сборка проходят локально;
- 4 базовых сценария: подготовка к встрече / архив / предложение темы / поиск материалов — пройдены вручную end-to-end.

Возврат к VPS, MiroTalk и production magic-link выделяется в отдельную фазу после появления бюджета или бесплатного подходящего хостинга.

## Phase 1: Workflow
Meetily для транскрибации, шаблон synthesis → publication, FAQ-копирайт, адаптив.

Задачи: DV-014, DV-015, DV-017, DV-018, DV-021..DV-023.

## Phase 2: Augmentation
open_deep_research, Twake Drive для тяжёлых медиа, тесты Cypress.

Задачи: DV-024, DV-025.

## Phase 3 (если)
Matrix/Element для комьюнити-чата, мобильное приложение, federation с другими ячейками.
