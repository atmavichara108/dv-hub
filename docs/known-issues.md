## 1. Telegram авторизация не работает

**Симптом**: Telegram Bot API возвращает 404 при вызове `getMe`, webhook endpoint работает корректно.

**Диагностика**:
- Формат токена правильный
- `getMe` возвращает `{"ok":false,"error_code":404,"description":"Not Found"}`
- Webhook endpoint `/webhook/telegram` отвечает 200
- Домен `re-search.wiki` зарегистрирован в @BotFather

**Статус**: Токен обновлён несколько раз, проблема не решена.

**Временное решение**: Email Magic Link работает корректно.

**Следующий шаг**: 
- Создать нового бота через @BotFather с другим username
- Или проверить токен через альтернативный метод
- Или использовать другой подход к Telegram авторизации

## 2. Неполная миграция данных из Cloudflare D1

**Симптом**: Отсутствуют последние темы и материалы которые были добавлены после начального экспорта.

**Диагностика**:
- Старые данные (2026-04-03) перенесены: 3 темы, 3 материала, 1 комната, 1 публикация
- Новые данные (добавленные позже) отсутствуют в локальной SQLite БД
- API `/api/dashboard` возвращает только старые данные

**Статус**: Миграция выполнена частично.

**Следующий шаг**:
- Повторный экспорт из Cloudflare D1: `wrangler d1 export dv-hub-production --output=./backup-latest.sql`
- Сравнить с локальной БД: найти недостающие записи
