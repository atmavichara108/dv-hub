Выполни:
1. `npm run context:status` — посмотри текущее состояние
2. `npm run context:sync` — подтяни последние изменения
3. `git diff context` — покажи что обновилось
4. Спроси у Макса: коммитить bump?
5. Если да — `npm run context:bump && git push`
